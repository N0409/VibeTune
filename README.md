# VibeTune 🎶

A sleek and modern music player web app to enhance your listening experience.

## Features 🌟
- Play, Pause, Next, and Previous song controls.
- Dynamic Playlist that automatically updates as you navigate through songs.
- Auto-play next song when the current one finishes.
- Responsive UI with a clean, dark mode theme.
- Displays cover images for each song.

## Tech Stack ⚙️
- HTML5: Structure of the app.
- CSS3: Styling with modern techniques.
- JavaScript: Core functionality and dynamic interactions.

## File Structure 📁
/VibeTune
├── index.html         # Main HTML structure
├── style.css          # Styling for the music player
├── script.js          # JavaScript functionality
├── assets/
│   ├── songs/         # MP3 files (e.g., fearless.mp3, skyhigh.mp3, blank.mp3)
│   ├── images/        # Album cover images (e.g., cover1.jpg, cover2.jpg, cover3.jpg)
│   └── icons/         # Play, pause, next, previous icons (SVGs)
└── README.md

## How to Run 🏃‍♂️
1. Clone the repository or download the files.
2. Open index.html in your web browser.
3. Enjoy the music player!

## Customization 🎨
- To add songs, simply place your .mp3 files in the assets/songs/ folder.
- Update the assets/images/ folder with corresponding cover images.
- Adjust the song titles and file names as needed in script.js.
